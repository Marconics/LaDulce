# LaDulce
Loja virtal para festas - bolos, doces, salgados, refrigerantes e demais itens para eventos e comemorações.

Projeto acadêmico desenvolvido em grupo, aplicando conceitos de desenvolvimento web full-stack, modelagem de banco de dados relacional e integração com um back-end como serviço (BaaS). 

LaDulce simula uma solução completa de comércio digital, permitindo que os usúários realizem login e cadastro, naveguem pela vitrine da página inicial que possui o catálogo de produtos disponíveis. LaDulce também simula uma compra real, direcionando o cliente para a área de pagamentos e finalização de compra.

Tecnologias utilizadas: 
<p>Front-end: HTML, CSS, JavaScript</p>
<p>Back-end: Node.js + Express </p>
<p>ORM: Prisma</p>
<p>Banco de dados: SQL (PostgreSQL, via Supabase)</p>
<p>Back-end como serviço: Supabase (banco de dados e/ou storage de imagens)</p>
<p>Ferramentas: Visual Studio Code, REST Client</p>
<p>Versionamento: Git/GitHub</p>
